# Computing Mathematics labs

Interactive tutorial pages for CMA1C03, served by GitHub Pages at
<https://shamim-akhtar.github.io/cmaths/>.

Each lab is a single self-contained HTML file. The maths typesetting engine
(MathJax 3.2.2, tex-svg build) is embedded in the file, so a page keeps working
with no internet connection once a student has it open or saved.

## Layout

    index.html          landing page listing the weeks
    week02/index.html   Week 2, Matrices and Matrix Operations
    .nojekyll           serve the files as they are, no Jekyll build

## Adding a week

Create `weekNN/index.html` and add a card to `index.html`.
